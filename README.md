# 🧮 けいさんカード（デジタル計算カード）

小学1年生の算数で使う「計算カード」を、**ブラウザだけ**で楽しめるようにしたアプリです。
インストールやサーバーは不要。GitHub Pages に置くだけで、タブレットやパソコンですぐ使えます。

![card](https://img.shields.io/badge/React-18-61dafb) ![pages](https://img.shields.io/badge/GitHub%20Pages-OK-success)

---

## ✨ できること

| カード | 中身 | まいすう |
|--------|------|:---:|
| 🍎 **あかカード** | たしざん（くりあがり なし・和が10まで） | 64 |
| 🐬 **あおカード** | ひきざん（くりさがり なし） | 65 |
| 🌟 **きいろカード** | たしざん（くりあがり あり・和が11〜18） | 36 |
| 🍀 **みどりカード** | ひきざん（くりさがり あり） | 36 |

- **2つのモード**：「じゅんばん」（小さい順）と「バラバラ」（シャッフル）
- **タイム計測**：そのカードを全部こたえ終わるまでの時間を自動で計測
- **3通りの操作に対応**
  - タップ：カードをタップ → **答えだけ**が表示 → **左スワイプで○せいかい** ／ **右スワイプで×もう一度**
  - ボタン：「こたえを みる」「せいかい」「もう一度」
  - **キーボード**：**スペース**（または Enter）でめくる ／ **←** せいかい ／ **→** もう一度
  - まちがえたカードは最後にもう一度出ます
- **カードのおもて＝式だけ**（例：`3 ＋ 4`）、**うら＝答えだけ**（例：`7`）。画面中央に大きく表示します
- **ベストタイム記録**：ブラウザに自動保存（ページを閉じても残ります）

## 🚀 つかいかた（GitHub Pages で公開する手順）

プログラミングの知識はいりません。次の通りに進めてください。

1. この **リポジトリ** をご自分の GitHub アカウントに用意します
   （すでに用意されている場合はそのままでOK）。
2. GitHub のページで **「Settings（設定）」** を開きます。
3. 左メニューの **「Pages」** をクリックします。
4. 「Build and deployment」の **Source** を **「Deploy from a branch」** にします。
5. **Branch** を `main`（または公開したいブランチ）、フォルダを **`/ (root)`** にして **Save**。
6. 1〜2分まつと、ページの上の方に公開アドレス（`https://◯◯◯.github.io/...`）が表示されます。
7. そのアドレスを開けば、アプリが動きます。タブレットでもどうぞ！

> 💡 アドレスを子どもたちのタブレットの「ホーム画面に追加」しておくと、
> アプリのように1タップで開けて便利です。

## 🗂 ファイルの説明

| ファイル | 役わり |
|----------|--------|
| `index.html` | アプリの入れもの。React や Tailwind の読み込みをします（ふつうは触りません） |
| `App.jsx` | **アプリの本体**。中身を変えたいときはここを編集します |
| `.nojekyll` | GitHub Pages が正しく動くためのおまじない（中身は空でOK） |

`App.jsx` は1ファイルに全部の画面・しくみ・見た目（Tailwind）が入っています。
コメント（説明文）をたくさん入れてあるので、少しずつ変えてみてください。

## 🎨 デザインについて

- フォント：計算式・数字は Windows の **UDデジタル教科書体** を最優先。無いときは
  丸ゴシック（Zen Maru Gothic／Kosugi Maru）に自動で切り替わります。
  画面のUI・見出しは落ち着いた角ゴシック **Zen Kaku Gothic New** を使用。
- 落ち着いた背景・余白・線画アイコンで、シンプルで読みやすい画面にしています。
  ボタンには「押し込み感」のあるアニメーションを付けています。
