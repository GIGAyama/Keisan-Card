# 🧮 けいさんカード（デジタル計算カード）

小学1年生の算数で使う「計算カード」を、**ブラウザだけ**で楽しめるようにしたアプリです。
サーバーは不要。GitHub Pages に置くだけで、タブレットやパソコンですぐ使えます。
**PWA対応**なので、Chrome などから「アプリ」としてインストールでき、一度ひらけば
**オフラインでも**動きます。

![card](https://img.shields.io/badge/React-18-61dafb) ![pages](https://img.shields.io/badge/GitHub%20Pages-OK-success) ![pwa](https://img.shields.io/badge/PWA-installable-5a0fc8)

## ✨ できること

| カード | 中身 | まいすう |
|--------|------|:---:|
| 🍎 **あかカード** | たしざん（くりあがり なし）足される数1〜9・足す数1〜9・和1〜10（`1+0`〜`9+0`をふくむ） | 54 |
| 🐬 **あおカード** | ひきざん（くりさがり なし）引かれる数1〜10・引く数1〜9・差0〜9（`1-1`〜`9-9`をふくむ） | 54 |
| 🌟 **きいろカード** | たしざん（くりあがり あり・和が11〜18） | 36 |
| 🍀 **みどりカード** | ひきざん（くりさがり あり） | 36 |

- **2つのモード**：「じゅんばん」（小さい順）と「バラバラ」（シャッフル）
- **タイム計測**：そのカードを全部こたえ終わるまでの時間を自動で計測
- **3通りの操作に対応**
  - タップ：カードをタップ → **答えだけ**が表示 → **左スワイプで○せいかい** ／ **右スワイプで×もう一度**
    （スワイプ中は、カードの上に **✓わかった**（左）／**✕もういちど**（右）が出るので、どちらに仕分けるか ひと目でわかります）
  - ボタン：「こたえを みる」「せいかい」「もう一度」
  - **キーボード**：**スペース／Enter** で「めくる→せいかいして つぎへ」。**連打するとどんどん進みます**。
    まちがえたときは **→**（もう一度）、せいかいは **←** でもOK
  - まちがえたカードは最後にもう一度出ます
- **カードのおもて＝式だけ**（例：`3 ＋ 4`）、**うら＝答えだけ**（例：`7`）。画面中央に大きく表示します
- **1かいめで せいかい**：結果画面に「一発で こたえられた まいすう」を表示。
  このアプリは ぜんぶ正解するまで終わらないので、タイムと ならぶ力の目やすになります
- **ベストタイム記録**：ブラウザに自動保存（ページを閉じても残ります）
- **せいちょうの きろく**：カードごとの **取り組んだ回数**・ベストタイム・前回タイム・
  最近のタイムの**棒グラフ**を表示。続けるほど成長が見えます（タイトル画面の「せいちょうの きろく」から）

### 🌟 まいにち つづけたくなる しくみ（1年生むけ）

- **れんぞく記録（🔥○にち れんぞく）**：まいにち取り組むと日数がのびます。
  1日あくとリセット。タイトル画面と きろく画面に表示します
- **がんばりカレンダー**：今月の「れんしゅうした日」に ★スタンプ がつきます
- **スタンプ**：1回クリアするごとに +1。ぜんぶで何こ集まったかが見えます
- **クリアのお祝い**：紙ふぶき＋ほめ言葉、しんきろく（ベスト更新）はとくべつ表示
- **こうか音・バイブ**：せいかい／まちがい／クリアで やさしい音。せっていで OFF にできます

## 📊 学習ログ（`study.v1`）

GIGA山の学習アプリ 共通の学習ログ仕様 **`study.v1`** に対応しています。
1回ぶんの取り組みが終わる（または とちゅうで やめる）たびに、
記録を **この端末の中だけ** に ためます。

> **このアプリが出すスキーマ版：`study.v1`**（仕様書 1.4 に対応）

### 何を ためているか

| 中身 | れい |
|------|------|
| どのカード・どのモード・いつ・どれだけの時間 | あかカード／じゅんばん／2026-07-27T09:12:00+09:00／128.4秒 |
| **1かいめで せいかいした まいすう**（いちばん大事な指標） | 54まい中 51まい |
| カード1枚ごとの 正誤・こたえた回数・かかった時間 | `8+5` は 2回目で せいかい・4.2秒 |
| このアプリだけの数字（ベストタイム・れんぞく記録 など） | `ext` に入ります |

**「1かいめで せいかい」を 主な指標にしています。** このアプリは ぜんぶ
正解するまで 終わらないため、「正解した数」は いつも まいすうと同じに
なってしまい、力の目やすになりません。結果画面にも 出しています。

### 大事なきまり

- **送信は しません。** ためるだけです。外へ送るのは、同じサイトに置かれた
  別のページ（送信ページ）の仕事です
- **だれの記録かは 持ちません。** 氏名・出席番号・メールアドレスは
  入れません。だれのものかは 送信ページが つけます
- **とちゅうで やめた記録も のこします**（`status: "aborted"`）。
  「むずかしすぎる」「量が多すぎる」の大事な合図だからです
  （1枚も こたえずに やめたときは 記録しません）

### とちゅうで やめたときの あつかい

つぎの3つを 中断として 記録します。

| きっかけ | どうなるか |
|---|---|
| 「やめる」ボタン・ヘッダーのホーム・端末の「もどる」 | その時点で 1件 のこす |
| **5分いじょう** タブを はなれた | **はなれた時刻**で 1件 のこす |
| タブが 閉じられた・こわされた（`pagehide`） | その時点で 1件 のこす |

- **待っていた時間は 学習時間に 入れません。** はなれた時刻で締めるので、
  5分の離席が `elapsedMs` に入って 学習時間が 水増しされることが ありません
- **4分の離席では 締めません。** 先生の説明を聞くための 数分の離席が
  中断として 記録されてしまうためです
- **もどってきたら、のこりの枚数で 新しい1件を 始めます。**
  締めた記録に あとから 書きたすことは しません。
  そのため 1回のれんしゅうが 2件以上の記録に わかれることがあります
  （そのときは `count` が カードの全枚数より 少なくなります）
- 画面の すすみ具合・クリアタイム・ベストタイムは わかれません。
  わかれるのは **学習ログだけ** です

> Chromebook は メモリ不足やスリープで タブを こわすことがあります。
> `pagehide` で確定しないと、そのとき 記録中のぶんが まるごと 消えます。

### 保存場所についての注意（重要）

学習ログは `localStorage` の **`study.records.v1`** に入ります。

> `study.records.v1` は複数アプリ共通の学習ログです。このアプリ専用のキーではないため、
> リセット処理やクリーンアップの対象に含めないでください。

このアプリのキーは `keisan-card-` で始めるきまりですが、
**`study.records.v1` は アプリ間で 共有するための わざとの例外** です。
「きろくを すべて けす」で 消えるのは `keisan-card-` の記録だけで、
学習ログは のこります（まだ送っていないログが 消えてしまうため）。
`localStorage.clear()` も 同じ理由で 使ってはいけません。

### `studyLog.js` について

保存のしくみは `studyLog.js` にまとめてあります。**ロジック本体は
5つのアプリすべてで同じ**にするファイルなので、改訂したら 1本だけでなく
全部に配り直し、仕様書 §5.1.3 の追跡表を 更新してください。

| 項目 | 値 |
|---|---|
| ロジック版 | **1.1**（仕様書 §5.1.2 の参照実装） |
| 配布形態 | **グローバル**（`globalThis.StudyLog.saveStudyRecord`） |

仕様書 §5.1.1 は ESM と グローバルの2形態を 認めています。
このアプリは ビルドをせず `<script>` で動かす構成のため グローバル形態です。
呼び出し側は、`studyLog.js` が 読みこまれていなくても アプリが動くよう、
存在を たしかめてから 呼びます。

### 📱 スマホ・タブレットの「もどる」操作

- **画面下のナビゲーションバーの「戻る」** や、**画面の左右のふちから中央へのスワイプ**
  （ジェスチャー操作）で、**アプリの中の1つ前の画面**にもどれます
  （パソコンのブラウザの「戻る」ボタン・`Alt`＋`←` も同じです）
- 1回の操作で**1つの階層だけ**もどります。階層は
  `タイトル → カードをえらぶ → モードをえらぶ → れんしゅう／けっか` の順です
  （「せいちょうの きろく」はタイトルへ、「せってい」がひらいているときは まずそれを とじます）
- **アプリが終了したり、ブラウザが前のサイトへ移動したりしません**。
  タイトル画面で「もどる」をすると「もう1かい「もどる」で とじます」と表示し、
  **つづけてもう1回**操作したときだけ とじます（あやまって閉じてしまうのを ふせぎます）

## 🚀 つかいかた（GitHub Pages で公開する手順）

プログラミングの知識はいりません。次の通りに進めてください。

1. この **リポジトリ** をご自分の GitHub アカウントに用意します
   （すでに用意されている場合はそのままでOK）。
2. GitHub のページで **「Settings（設定）」** を開きます。
3. 左メニューの **「Pages」** をクリックします。
4. 「Build and deployment」の **Source** を **「Deploy from a branch」** にします。
5. **Branch** を `main`（または公開したいブランチ）、フォルダを **`/ (root)`** にして **Save**。
6. 1〜2分まつと、ページの上の方に公開アドレス（`https://◯◯◯.github.io/...`）が表示されます。
7. そのアドレスを開けば、アプリが動きます。タブレットでもどうぞ！

> 💡 アドレスを子どもたちのタブレットの「ホーム画面に追加」しておくと、
> アプリのように1タップで開けて便利です。

|----------|--------------------|
| `js/app.js` | `src/App.jsx`（ビルド時に1回だけ JSX を翻訳） |
| `css/style.css` | `src/styles.css` ＋ `tailwind.config.js` |
| `vendor/react*.js` | `node_modules`（npm でバージョンを固定） |

> ### ⚠️ 原本を直したら、かならず `npm run build` を実行してから push すること
>
> GitHub Pages は このリポジトリの中身を **そのまま配るだけ** で、
> ビルドを走らせません。`src/` を直しただけでは 何も変わりません。
> 忘れても気づけるよう、CI が `node tools/build.mjs --check` で
> 「生成物が原本と食いちがっていないか」を見張っています。

```bash
npm install       # はじめに1回
npm run build     # src/ を直したら かならず
npm run check     # CI と同じもの（生成物の照合・品質ゲート・テスト）
npm run measure   # 実ブラウザで測る（コントラスト・タップ・PWA・オフライン）
```

### なぜ ビルドを入れたか

以前は `index.html` から `cdn.tailwindcss.com` / `unpkg.com` の React /
`@babel/standalone` を読み、**ひらくたびに ブラウザの中で JSX を翻訳** していました。
学校のネットワークは これらの CDN を ふさいでいることがあり、
1本でも 届かないと **画面が真っ白のまま 何も出ません**。
しかも 原因は アプリの外にあるので、先生が調べても 分かりません。
`@babel/standalone` だけで 約3MB あり、それを 毎回 読んで 毎回 翻訳していました。

いまは 全部 先に作って 自分側に置いてあります。

| | 前 | 後 |
|---|---:|---:|
| ブラウザに送る実行コード | 約 3.3 MB（うち CDN 3本） | **205.9 KB（CDN 0 バイト）** |
| CDN が塞がれたとき | 画面が出ない | ふつうに動く |

## 📱 アプリとしてインストールするときの注意（重要）

`https://gigayama.github.io/` には たくさんのアプリが 同居しています。
ブラウザ（とくに Chromebook）は **`manifest.webmanifest` の `id` と `scope`**
でアプリを見分けているため、ここが ほかのアプリと かぶっていると
**「このアプリのページが、別のアプリのウィンドウで開いてしまう」**
という 取りちがえが起きます。

そのため、このアプリでは 3つとも 配置パスの絶対パスで書いています。

```json
"id":        "/Keisan-Card/",
"scope":     "/Keisan-Card/",
"start_url": "/Keisan-Card/?source=pwa"
```

> **このリポジトリをコピーして 別のアプリを作るときは、この3つを
> かならず 新しいフォルダ名に 書きかえてください。**
> 書きかえ忘れに気づけるよう、`index.html` に自己点検を入れてあります。
> ずれていると 開発者ツールのコンソールに 警告が出ます。

**すでにインストール済みの端末について**：この修正で `id` を
明示したため、ブラウザから見ると「別のアプリ」になります。
**一度アンインストールしてから、入れ直してください。**
学習記録（れんぞく記録・ベストタイムなど）は ブラウザ側に
残るので、入れ直しても消えません。

### サイト全体で共有されるもの

| 共有されるもの | このアプリでの区切り方 |
|----------------|------------------------|
| PWA の識別子 | `manifest.webmanifest` の `id` / `scope` / `start_url` |
| CacheStorage | キャッシュ名を `keisan-` で始める（`sw.js` の `CACHE_PREFIX`） |
| localStorage | キーを `keisan-card-` で始める（例外：共通の学習ログ `study.records.v1`） |

次の2つは **絶対に書かないでください**。同じサイトの ほかのアプリの
データまで 消してしまいます。

- `sw.js` の `activate` で、自分のもの以外のキャッシュを削除する
- `localStorage.clear()`（サイト全体の保存を消してしまいます）

## ⚙️ 動作に必要なもの

- パソコン／タブレット／スマートフォンのブラウザ（Chrome・Safari・Edge など）
- **アプリの動作に 外部のサーバーは いりません。** React もスタイルも本体も
  このリポジトリの中に入っているので、学校のネットワークが CDN を
  ふさいでいても 起動します
- 唯一の外部依存は **Google Fonts（見た目だけ）** です。届かなくても
  端末側の日本語フォントに落ちるだけで、動作は変わりません
- 一度ひらいたあとは、**オフラインでも動きます**（Service Worker がファイルを保存します）

## 🔒 セキュリティ

- `index.html` に **CSP（Content-Security-Policy）** を入れています。
  `script-src 'self'` なので、**インラインの `<script>` と `onclick=` は動きません。**
  JavaScript を足すときは かならず 外部ファイルにして `<script src>` で読んでください
- `frame-ancestors`（他サイトへの埋め込み禁止）は `<meta>` では無視されるため
  書いていません。独自ドメインや CDN を挟むときは、そちら側の
  HTTP ヘッダーで設定してください
- 個人情報は 一切 持ちません。学習ログにも 氏名・出席番号・メールアドレスは
  入りません（`study.v1` §0-2）
